# Projector：ESP32 语音 + 局域网网页，远程指挥台式机上的 Claude

```
微雪 ESP32-S3-Touch-AMOLED-2.16（小智固件）
   │ 语音
   ▼
小智云端（xiaozhi.me）：语音识别 → 大模型 → 调用 MCP 工具
   │ MCP 接入点（台式机主动连出，不需要公网 IP）
   ▼
台式机 Windows
 ├─ mcp_pipe.py + claude_mcp.py   小智 MCP 工具，转发到中心服务
 └─ server.py                     中心服务：账号、多会话、权限确认、技能库，调用 Claude Code（工作目录 D:\）
    store.py / files_api.py / skills_api.py / kb.py / approval_mcp.py
       ▲
       │ http://台式机名:8080（桌面软件在局域网里自动发现）
同事的电脑：Projector 桌面软件，或浏览器打开网页端
```

## 功能

- **账号**：管理员在台式机上给每个人建账号，同事只能登录、不能注册。每个人只看得到自己的会话、工作区和确认请求；管理员能按人查看所有聊天记录（只读）。
- **会话**：多个会话、回复逐字输出、显示 Claude 读了哪些文件和做了哪些操作、可以中途停止。“完整过程”可以看 Claude Code 保存的每一步思考和工具调用。
- **工作文件夹**：每个会话可以选一个文件夹（顶栏 📂），Claude 就在那里干活，不同会话互不干扰。只能在会话开始前选。
- **📎 引用文件**：从文件库（D 盘）选文件或文件夹，或在输入框里打 `@`，作为标签随消息发给 Claude。
- **工作区**：每个人上传的本机文件、Claude 取出来修改的技能都放在 `D:\Projector工作区\<显示名(用户名)>\<日期 会话标题>\`，在 D 盘里就能直接找到。普通用户在文件库里只能进自己的那份；会话改名后文件夹名不变。可以用环境变量 `WORKSPACE_ROOT` 改位置。
- **💻 本机文件**：把同事自己电脑上的文件交给 Claude。文件上传到台式机上这个人的工作区（别人看不到），Claude 在那里处理，用的是台式机上的技能。
  - 桌面软件里“添加本机文件夹”：处理完点“查看改动 / 同步回本机”，把新增和修改的文件写回原文件夹；被覆盖的原文件先备份到那里的 `.projector备份` 文件夹。
  - 也可以直接把文件拖进窗口；浏览器里处理结果逐个下载。
- **🧩 技能**：每个人都能提交 skill（含 `SKILL.md` 的文件夹或 zip），管理员审核后入库，再分配给指定的人或所有人。输入框旁的 🧩 只列出分配给自己的技能，选中后 Claude 会用它完成这次任务；不选时 Claude 也会在已分配的技能里自动判断。
  - **版本**：每次审核通过记成一个新版本（v1、v2……）。技能详情里能看到每个版本是谁改的、改了什么、改了哪些文件；管理员可以回滚。
  - **在对话里改技能**：直接跟 Claude 说“帮我把周报技能加上下周计划”或“帮我做一个检查合同的技能”。Claude 会用 `skill_checkout` 把技能取到你的工作区、改好后用 `skill_submit` 提交新版本，管理员审核通过才生效。也可以在技能详情里点“在对话里修改”或“上传新版本”。
- **📱 手机**：手机连同一个 Wi-Fi，在个人菜单里点“在手机上打开”扫二维码即可；iPhone 用 Safari“添加到主屏幕”后像 App 一样全屏打开，安卓用 Chrome“添加到主屏幕”。手机上不能“同步回本机”和“用本机程序打开”。
- **📁 文件库管理**：所有人都能在文件库里上传文件和文件夹（也能直接拖进去）、新建文件夹、改名、删除。删除和被覆盖的文件进 `D:\Projector工作区\回收站`，保留 30 天，可以在网页里恢复；每一步操作都记在“管理后台 → 文件记录”。Projector 程序自己的文件夹和工作区根目录不能改。
- **📁 文件预览**：浏览、搜索 D 盘和自己的工作区。图片、PDF、音视频、文本（自动识别 GBK）、Markdown、Word、Excel 直接预览；PPT、老版 Word、WPS 需要台式机装 [LibreOffice](https://zh-cn.libreoffice.org/download/download/)；预览不了的，桌面软件里可以“用本机程序打开”。Claude 回复里的路径也能直接点开。
- **💬 Claude 提问卡片**：Claude 需要你拿主意时（用哪个模板、处理哪几个月……），输入框上方会弹出选项卡片，像 Claude 桌面端那样点选即可：按数字键选、回车提交，可以多选、填“其他”、加备注，也可以“跳过，让 Claude 自己决定”。问答会留在聊天记录里。语音会话里 Claude 会改成口头问。
- **📖 知识库**：见下面一节。
- **语音**：板子上的语音任务都放在“板子”账号下，管理员可以给它分配技能、查看记录。

## 知识库

把团队的经验和重要文件串起来，Claude 回答问题前会先查这里。

- **存在哪**：`D:\知识库`，就是一堆 Markdown 笔记，格式和 [Obsidian](https://obsidian.md) 一样，想看关系图也可以直接用 Obsidian 打开这个文件夹（日常在网页里用就行）。可以用环境变量 `KB_ROOT` 改位置。
- **三类笔记**：
  - **经验**：做成过一件事以后的背景、做法、用到的文件、踩过的坑。在 Claude 的回答下面点 **“沉淀成经验”**，Claude 会整理成笔记（有相关的旧笔记就合并进去）。
  - **文件卡片**：重要文件或文件夹的摘要、关键信息（金额、日期、对方……）和位置。在文件库里选中文件或文件夹点 **“整理进知识库”**，Claude 会新开一个会话读文件、写卡片。原文件改过后，卡片会提示“可能过时”，点“让 Claude 更新”即可；文件库预览文件时也会提示“知识库里有这份文件的卡片”。
  - **主题**：项目、客户、供应商、产品等，把相关的经验和卡片连在一起。
- **链接**：笔记里写 `[[笔记名]]` 就连上了，链接到还没写的笔记也可以（虚线显示，点一下就能新建）。Claude 回答里的 `[[笔记名]]` 也能直接点开。笔记改名时，其他笔记里的链接会跟着改。
- **网页里**：侧栏“知识库”或顶栏 📖。首页看统计、最近更新、常被提到的主题、需要更新的卡片；“笔记”里按类型和标签筛选、全文搜索、阅读、编辑（输入 `[[` 会提示笔记名）；“关系图谱”看笔记之间怎么连在一起。
- **Claude 怎么用**：遇到和公司业务、项目、客户、以前做过的事有关的问题，会先用 `kb_search` 查；用 `kb_write` 写（只在你要求时写，自动记作者）；用 `read_document` 读 Word、Excel、PPT、PDF 的文字（老版 .doc/.xls 需要 LibreOffice）。
- **改错了能恢复**：每次修改都留历史版本（网页里“历史”可以恢复）；删除的笔记进回收站。所有人都能看、能改知识库，修改记在“管理后台 → 文件记录”。
- **注意**：知识库对所有人可见，不要把薪资、身份证号、银行卡号这类内容写进去。

## 权限

管理员在“管理后台 → 设置”里选权限档位，对所有人生效：

| 档位 | 自动执行 | 要确认 |
|---|---|---|
| **标准（默认）** | 读文件、改文件、运行 python / unzip / tar 等所有命令 | 删除、移动、格式化、改系统、强制推送等危险命令（名单可改） |
| 严格 | 读文件、ls / cat 等只读命令、管理员加的白名单命令；网页会话改文件 | 其他所有操作；语音会话改文件也要确认 |
| 完全放行 | 全部，不再询问 | 无。管理员在“用户”里按人开通，语音会话不能用 |

- 确认请求只推送给会话主人（和管理员）。语音这边，小智会把要做的操作念出来，你说“同意”或“拒绝”。30 分钟没人确认就自动拒绝。
- 标准档靠命令开头匹配：写 `rm` 能拦住 `rm -rf 文件夹`，但用 python 脚本删文件这类间接操作拦不住。
- **隔离是软隔离**：所有人的 Claude 都以台式机上同一个 Windows 账号运行。界面、记录、工作区各管各的，Claude 用文件工具读写别人的工作区和系统数据会被拦住；但让 Claude 用命令去翻，是拦不住的。
- **技能里的脚本**会在台式机上以完整权限运行，管理员审核时要看代码（审核页会标出脚本文件和这次改动的文件）。
- **排查**：每个会话的 Claude 报错写在 `data/logs/claude_<会话id>.log`，权限确认工具的记录在 `data/logs/approval_mcp.log`。如果聊天里提示“权限确认通道出了故障”，重发一次通常就好，反复出现就看这两个日志。

## 在台式机上安装

1. 安装 [Python 3.10+](https://www.python.org/downloads/)，安装时勾选 “Add python.exe to PATH”。
2. 安装 Claude Code 并完成登录或配置（用 DeepSeek 的话，按 DeepSeek 文档设置 `ANTHROPIC_BASE_URL` 等环境变量，也可以写进 `config.bat`）。在命令行里运行 `claude -p "你好"`，能正常回答就说明可以用了。服务端找 `claude` 时会先看 PATH，找不到再去常用安装位置（官方安装器、npm、nvm、Volta、Scoop、WinGet）找；都找不到可以在 `config.bat` 里设 `CLAUDE_BIN`。
3. 到仓库的 [Releases](https://github.com/luckytiger125/Projector/releases) 页下载最新的 `Projector-server-vX.Y.Z.zip`，解压到任意文件夹（路径最好不带中文）。
4. 双击 `install.bat`：检查 Python 和 Claude Code、建好 `.venv` 装依赖，并引导你生成 `config.bat`（小智的 MCP 接入点、工作目录）。
5. 双击 `start.bat`。第一次运行时 Windows 防火墙会弹窗，选择允许 **专用网络**（网页端用 TCP 8080，自动发现用 UDP 8090）。
6. 在台式机本机的浏览器打开 `http://localhost:8080`，**创建管理员账号**（只能在本机创建）。然后在“⚙ 管理 → 用户”里给同事建账号。
7. 台式机 `~/.claude/skills` 里原有的 skill 会对所有人生效。到“⚙ 管理 → 技能库”里一键导入技能库，再把原文件夹里的移走，之后就按分配生效。
8. 忘了管理员密码：在项目文件夹里运行 `.venv\Scripts\python server.py reset-password 用户名 新密码`。

从 v0.5 升级：覆盖文件后重新双击 `install.bat`（要多装一个读 PDF 用的 `pypdf`），再启动。知识库文件夹会自动建好。

从 v0.4 及更早升级：原来放在 `data\workspaces` 里的工作区会在启动时自动搬到 `D:\Projector工作区`。

从 v0.2 升级：覆盖文件后重启。原来的访问密码（`CENTER_TOKEN`）不再使用，原来的会话会归到第一个管理员名下，语音会话归到“板子”账号。

## 使用

- **同事**：装好桌面软件，打开后会自动找到局域网里的台式机，点一下，用管理员给的账号登录。浏览器也可以打开 `http://台式机名:8080`。
- **台式机本机**：浏览器打开 `http://localhost:8080`，或者装桌面软件并打开“服务端模式”。
- **手机**：个人菜单 → “在手机上打开”，扫码。
- **板子**：直接说，比如“让电脑帮我找一下 D 盘里上个月的合同”。耗时长的任务会先回复“已开始”，稍后问“任务进度”就能听到结果。

## 桌面软件（Windows）

`desktop/` 是一个用 Tauri 做的桌面壳子，窗口里就是上面的网页端，另外多了托盘图标和系统通知。

**下载安装**

1. 到仓库的 [Releases](https://github.com/luckytiger125/Projector/releases) 页，下载最新版本里的安装包，任选一个：
   - `Projector_x.x.x_x64-setup.exe`：推荐，装到当前用户下，不需要管理员权限
   - `Projector_x.x.x_x64_zh-CN.msi`：适合统一部署
2. 安装包没有签名，Windows 可能提示“已保护你的电脑”，点“更多信息” → “仍要运行”。
3. 第一次打开会自动查找局域网里的台式机，点一下就行；找不到时手动填 `http://台式机名:8080` 或 `http://台式机IP:8080`。之后打开软件直接进入登录页。

**使用**

- 关闭窗口不会退出，而是缩到右下角托盘；单击托盘图标显示/隐藏窗口。
- 托盘菜单：显示/隐藏窗口、重新加载、修改服务器地址、服务端模式、打开日志文件夹、退出。
- 有待确认的操作时，窗口不在前台也会弹 Windows 通知。

**服务端模式（只在台式机上打开）**

打开后不再需要 `start.bat`：软件开机自动启动（缩在托盘），在后台无窗口地运行 `python server.py` 和 `python mcp_pipe.py claude_mcp.py`，进程崩溃会自动重启；托盘菜单里能看到两个进程是否在运行。

1. 先按上面“在台式机上安装”运行 `install.bat`，并确认双击 `start.bat` 能正常用（之后关掉 `start.bat` 的窗口，避免端口冲突）。
2. 在设置页勾选“服务端模式”，项目文件夹填本仓库所在的文件夹（`server.py` 和 `config.bat` 所在的位置）。也可以从托盘菜单勾选。
3. 环境变量读取 `config.bat` 里的 `set` 行；改了 `config.bat` 后在托盘里关掉再打开服务端模式即可生效。想指定 Python，可以在 `config.bat` 里加 `set "PYTHON=C:\路径\python.exe"`；项目文件夹里有 `.venv` 时会自动使用。
4. 进程输出写在日志文件夹的 `server.log` 和 `mcp_pipe.log` 里（托盘 → 打开日志文件夹）。

**自己构建**

推送到 `main` 且改动了 `desktop/` 时，GitHub Actions 会在 Windows 上自动构建安装包（在 Actions 页的 Artifacts 里）；也可以手动点 “Run workflow”。推送 `v` 开头的标签（比如 `git tag v0.1.1 && git push origin v0.1.1`）会自动发 Release。发版前记得同时改 `desktop/src-tauri/tauri.conf.json` 里的版本号。在 Mac 上开发调试：

```bash
cd desktop && npm install && npm run tauri dev
```

## 已知限制

- 语音指令会被小智的大模型转述一次，原话可能被改写；Claude 实际收到的内容可以在对应的 🎤 会话里查看。
- 接 DeepSeek 等第三方模型时，Claude Code 的 WebSearch（联网搜索）用不了。
- 小智云端只在你说话时才会调用工具，所以任务完成、或者中途需要确认时，没法主动通知到板子，需要问一下“任务进度”。要做到主动推送，得自己部署 xiaozhi-esp32-server。
- 所有人共用同一个 D 盘。给会话选好各自的工作文件夹能减少冲突，但两个人同时改同一个文件仍可能互相覆盖。
- 自动发现靠局域网广播，有的公司网络（访客 Wi-Fi、开了 AP 隔离、跨网段）会拦住，这时手动填地址。
